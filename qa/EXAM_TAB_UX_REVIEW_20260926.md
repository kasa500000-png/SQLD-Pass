# SQLD Pass 실전 탭 UX 검토 — 2026-09-26

## 결론

현재 회차 카드와 응시 안내 구조는 유지해도 된다. **응시 안내에서 돌아올 때 목록 위치가 사라지는 동작은 수정할 가치가 있다.** 함께 손본다면 반복되는 회차 정보와 이용 불가 버튼을 줄이고 응시 가능한 회차 수를 보여 주는 정도를 권장한다. 전면 리디자인의 필요성은 이번 관찰에서 확인되지 않았다.

## 확인 대상과 범위

- 연결된 실제 기기: Samsung SM-F721N, 1080×2640, density 480.
- 설치본: `com.sqldpass.app.internal`, 0.1.0 / versionCode 1, 업데이트 2026-09-26 19:56:57. 최신 홈·학습 개선이 포함된 검증용 앱이다.
- `com.kasa500000.sqldpass` Play 패키지는 기기에 설치되어 있지 않았다. 따라서 이번 결과를 현재 스토어 배포본의 직접 검증으로 표현하지 않는다.
- 소스 기준: `main`의 `cfef92b`. 앞서 검증한 `5fcb9ea`와 소스 트리가 동일하다.
- 전체 목록을 1회차부터 20회차 끝까지 이동해 9개 화면과 UI 트리를 수집했다. 실제 표시 영역 안에 들어온 회차별 버튼 20개를 모두 확인했다. 1~4회는 활성, 5~20회는 비활성으로 광고 off 정책과 일치했다.
- `전체 20회` / `지금 응시 가능` 필터, 4회차 응시 안내 및 뒤로 가기, 1회차의 큰 글자 응시 안내와 목록 복귀, 앱 글자 크기 100% / 130%를 확인했다.
- 실제 `90분 실전 시작`은 누르지 않았다. 진행 중 시험·답안표·채점·결과·재응시 상태, 실제 광고 해제, TalkBack 음성, iOS·태블릿 실행은 이번 확인 범위에 포함하지 않는다.

## 권장 개선

| 우선순위 | 실제 관찰 | 사용자 영향 | 권장 변경 |
|---|---|---|---|
| 높음 | `지금 응시 가능`에서 4회차까지 내려간 뒤 응시 안내를 열고 `뒤로`를 누르면 1회차가 있는 맨 위로 돌아왔다. 필터 선택은 유지됐다. | 회차를 확인하거나 비교할 때 같은 위치를 다시 찾아야 한다. 학습 탭에서 개선한 목록 복귀와도 동작이 다르다. | 실전 목록도 선택한 필터와 보던 위치를 함께 보존한다. 시험 본문이나 답안 데이터와 구분된 탐색 상태로 처리한다. |
| 중간 | 모든 카드에 같은 `1과목 10문항 · 2과목 40문항`이 반복된다. 현재 광고 off 상태에서는 5~20회에 큰 `현재 테스트에서 이용 불가` 버튼도 반복된다. | 실제로 고를 수 있는 회차에 비해 목록이 길고 동일 정보를 계속 읽게 된다. | 공통 구성은 상단 또는 응시 안내에 모으고 카드에는 회차·응시 상태·해당 행동을 중심으로 남긴다. off 상태의 이용 불가 회차는 큰 비활성 버튼을 짧은 상태 표시로 줄인다. |
| 낮음 | `지금 응시 가능`을 선택하면 실제로 4개가 남지만 필터에는 개수가 없고 상단은 전체 보유량인 20회만 표시한다. | 지금 선택할 수 있는 회차 수를 바로 파악하기 어렵다. | 현재 접근 권한을 기준으로 `응시 가능 4회`처럼 동적으로 표시한다. 무료 4회로 숫자를 고정하지 않는다. |

두 번째 항목은 **표시 밀도의 개선**이다. 5~20회의 잠금 자체는 현재 검증용 앱의 정상 정책이며, 광고 활성화나 임의 회차 해제를 권장하는 뜻이 아니다. 광고 활성화 시에는 선택한 회차를 여는 실제 동작과 기기 저장 안내를 유지한다.

우선순위는 **목록 복귀 수정 → 카드 중복 정보 정리 → 응시 가능 수 표시**다. 이 정도를 적용한 후 다른 탭으로 넘어가도 충분하다고 판단한다.

## 유지해도 좋은 부분

- 회차 제목, 무료/이용 불가 상태, 미응시 상태와 파란 응시 버튼이 구분되어 있다.
- 응시 가능 필터는 실제로 1~4회만 남기고 목록의 끝도 4회차다. 응시 안내에서 돌아와도 해당 필터는 유지된다.
- 100% 응시 안내 첫 화면에 `90분 실전 시작`이 보인다. 시간 제한, 화면을 나가도 시간 진행, 미응답 처리, 제출 후 변경 불가 안내가 명확하다.
- 130%에서는 안내 화면을 한 번 스크롤하면 시작·목록 버튼과 마지막 안내까지 확인할 수 있다. 이번 확인에서 글자가 카드나 버튼 밖으로 넘치는 문제는 관찰하지 않았다. 화면 아래의 내용을 스크롤로 보는 정상 동작을 잘림 결함으로 분류하지 않는다.
- 실전 목록과 안내에 배너는 표시되지 않았다. 이번 실행의 광고 모드는 off다.

## 보조 접근성 관찰

회차별 버튼의 UI 트리 접근성 이름이 모두 `응시 안내 보기`로 동일했다. 버튼 단위 탐색에서 회차를 구분하도록 접근성 이름에 회차 번호를 포함할 수 있다. 이는 UI 트리와 코드에 근거한 제안이며 실제 TalkBack 낭독 테스트를 완료했다는 뜻은 아니다.

- 진입 전: 4회차 제목 Y=1728px, 해당 버튼 `[111,1944][969,2100]`.
