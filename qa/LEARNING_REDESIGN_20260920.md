# 홈 · 학습 · 실전 · 기록 리디자인

## 학습 앱 우선 설계

- 홈: 진행 중 시험/문제 이어하기 우선. 이론을 읽고 확인 문제를 남긴 경우 확인 문제로 연결.
- 학습: 이론 / 복습 / 북마크 전환. 복습에서도 학습 탭 선택 상태 유지. 검색·과목 필터 유지.
- 실전: 짧은 회차 제목, 무료·해제·이용 불가 상태 구분. 광고 off 상태에서 작동하지 않는 광고 CTA 제거.
- 기록: 첫 풀이 정답률과 확신 정답 비율 구분, 제출된 시험의 날짜·점수·첫 응시/재응시·결과 링크.
- 설정: 상단에 일관된 진입점. 고객지원·개인정보·콘텐츠 버전 배치.
- 휴대전화: 터치 영역 유지, 제목·카드 여백 축소. 하단 탭 아이콘과 텍스트 및 접근성 tab 역할.
- 태블릿: 본문 최대 폭 920, 학습 목록 2열. 큰 글자는 1열 유지.

## 보존 범위

기존 SQLite 상태 스키마, 답안/문항/해설 원문, 시험 스냅샷·시간·저장·채점, 보상 해제 정책은 변경하지 않는다.
기록 화면의 통계는 저장된 답안으로 계산하며 합격 예측을 생성하지 않는다.
기존 'review' 내부 경로는 유지하고 하단 독립 탭만 학습 안으로 이동한다.
