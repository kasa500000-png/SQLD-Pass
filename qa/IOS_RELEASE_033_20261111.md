# iOS 0.3.3(13) 출시 기록 — 2026-11-11

## 최신 실행 지시와 검증 범위

소유자가 iPad 연결 대기 보고 후 “검증없이 앱스토어 정식 출시 진행, testflight도 업데이트”라고 직접 지시했다.
이번 0.3.3(13)에 한해 추가 실기기·동의·접근성 검사를 생략하고 TestFlight와 정식 심사 제출을 진행한다.
새 실기기 검사를 통과했다는 뜻이 아니며 향후 버전의 일반 QA 조건을 제거하지 않는다.

- 이전에 완료: 전체431개 자동 검사, 타입 검사, Expo doctor21/21, iOS375/402/1032pt·가로1376pt·최대 글자 시뮬레이터 흐름, SQLite 업데이트 보존. [통합 보고](UI_UX_20261111.md).
- 이번에 생략: 0.3.3 iPad 실기기 설치 후 동작, 새 지역별 동의 재실행, VoiceOver/TalkBack.
- 과거 증거: 기존 교재 빌드의 소유자 iPad 테스트 광고 관찰과 이전 iOS 시뮬레이터 UMP 검사. 현재 빌드의 새 실기기 증거로 재분류하지 않는다.
- 유지: 실제 빌드·서명·Apple 업로드 처리, 원본 콘텐츠 승인, 런타임 UMP/earned-reward/광고 표시 조건.
- 추가 모의고사21–60회는 포함하지 않는다. 콘텐츠 version/hash와 기존 학습 기록 보존 경로는 그대로다.

## 참고
