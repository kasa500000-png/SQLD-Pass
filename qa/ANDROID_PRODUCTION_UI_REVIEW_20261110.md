# Android 정식 배포 앱 UI·UX 실기기 리뷰 — 2026-11-10

## 검토 환경과 범위

Samsung SM-F721N, 세로 화면 1080×2640, density 480(약 360dp 폭), 시스템 글자 배율 1.0, 앱 밝게/100%. Google Play에서 com.kasa500000.sqldpass를 0.2.2(15) → **0.3.1(17)**로 실제 업데이트한 뒤 확인했다. 테스트 APK나 시뮬레이터 화면이 아니다. 기존 승인된 구교재 전환 안내가 표시됐으며 확인했다. 새 교재 기준 기록은 0건이고, 확인한 5~11회는 기존 이용 권한으로 열려 있었다.

28장의 화면 캡처(중복 상태 포함)를 남겼다. 홈·교재·문제·실전·기록 5개 탭, 장 목차, 본문/표/SQL, 검색, 핵심 카드 앞뒤, 용어 사전, 모의고사 안내·목록·빈 복습/저장/응시 기록, 설정·날짜 선택·알림·개인정보·도움말을 직접 확인했다.

**전체 상태 검증 완료는 아니다.** 제출된 모의고사 기록이 없어 진행·답안지·제출 결과·해설 화면은 검토용 응시 기록 1건 생성에 대한 사용자 답변 대기 중이다. 모든 216절·37개 위젯·1,340문항을 순회한 것이 아니다. 신규 온보딩, 잠긴 회차 광고, 광고 동의창, 오류/오프라인, 다크·확대 글꼴은 이번 실기기 관찰 범위에 포함하지 않는다. 운영 광고를 QA 목적으로 재생하거나 클릭하지 않았다. 문제풀이 첫 문항을 열었지만 답안은 제출하지 않았다. 검토 후 홈에는 미제출 문제풀이 이어하기와 마지막으로 연 SELECT 절의 이어읽기가 남아 있다. 읽음 완료·정답률·모의고사 점수는 생성하지 않았다. 앱 코드·출시 설정은 변경하지 않았다.

## 종합 판단

사용자가 느낀 ‘불필요하게 진한 UI’는 실제 화면에서도 확인된다. 핵심은 색상 하나가 아니라 **제목·선택 필터·보조 기능·주요 행동에 비슷한 시각적 강조를 주는 구조**다. 큰 제목, 거의 모든 버튼의 굵은 글자, 넓은 파란 면, 카드 속 카드, 과도한 세로 간격이 겹친다. 반면 본문은 일반 굵기로 읽을 만하므로 본문 대비까지 일괄 낮추면 안 된다.

가장 큰 UX 문제는 좁은 기기에서 짧은 선택지까지 전부 세로로 펼쳐지는 공통 반응형 처리다. 문항 수·응시 필터가 화면을 차지하고, 학습 본문은 고정 버튼에 밀린다. 색만 옅게 바꾸는 수정으로 해결되지 않는다.

## 우선순위

- **P1 — 학습 효율에 직접 영향:** 짧은 필터의 가로 배치, 교재 고정 푸터 축소, 모의고사 목록을 첫 화면으로 끌어올리기, 버튼 강조 체계 정리.
- **P2 — 탐색과 이해 개선:** 검색 문맥, 빈 상태 행동 안내, 기록 요약, 설정 복귀 위치 유지, 탭 고정 폭, 용어 사전 밀도.
- **P3 — 시각적 일관성:** 라이트 모드 SQL 배경, 날짜 선택기 강조색, 제목 크기·카드·모서리 정리.

## 코드와 대조한 원인

1. `src/ui/responsive-layout.ts:80`의 `stackRows: usableWidth < 360` 규칙. 이 기기 폭 약 360dp에서 좌우 16dp를 빼면 328dp이므로 작은 필터도 세로 처리된다. `src/platform/NativeView.tsx:121`은 adaptive-row의 모든 자식을 width 100%로 바꾼다. 버튼 종류·글자 길이를 고려하는 전용 segmented control이 필요하다.
2. `src/textbook/views.ts:13`의 공통 제목은 23sp/700으로 카드 제목·FAQ에도 동일 적용된다. 페이지 제목/섹션 제목/항목 제목을 분리해야 한다.
3. 같은 파일의 act는 일반 보조 행동을 모두 blueSoft, selected는 blue로 만든다. 선택 상태와 주요 행동을 구분하는 토큰이 필요하다.
4. `src/platform/NativeView.tsx:81`의 버튼 기본 글꼴은 600으로 보기와 목록에도 공통 적용된다. 선택지 본문과 진도 보조 문구는 별도 텍스트 스타일이 필요하다.
5. 교재 푸터는 adaptive-row 두 행동+다음 절 행이라 좁은 화면에서 3줄이 된다. 이는 캡처에서도 실제 확인했다.

## 권장 시각 규칙

본문의 명암 대비는 유지한다. 본문 16sp/400, 목록 제목 15~16sp/500~600, 섹션 18~20sp/600, 페이지 제목 22~24sp/600~700을 시작점으로 검증한다. 설명·수치·보기 전체에 굵기를 쓰지 않는다. 진한 채움은 한 영역의 핵심 행동 하나에 제한하고 선택 상태는 작은 면/테두리/표시로 구분한다. 터치 영역 48dp는 유지하되 시각적 패딩과 버튼 사이 간격을 줄인다. 카드는 정보 묶음에만 쓰고 모든 행을 개별 카드로 만들지 않는다.

## 개선 후 확인 기준

360dp 폭·기본 글꼴에서 문항 수 4개가 한 줄 또는 2×2, 실전 필터는 한 줄, 모의고사 목록은 첫 화면에 최소 3개 회차를 목표로 한다. 교재 하단은 기본 크기에서 1행 중심으로 정리하고 확대 글꼴에서는 조작 불가나 잘림 없이 재배치한다. 탭 중심 위치는 모든 화면에서 고정한다. 설정·검색·목록의 복귀 위치를 보존한다. 변경 후 실기기와 큰 글꼴을 다시 검증하며, 점수·진도·광고 보상/동의 정책은 시각 개선과 분리해 보존한다.
