# 새 모의고사 20회 통합

사용자가 승인한 전환 계획을 구현했다. 새 교재의 216절·340문항·37개 도구는 유지하고, 별도 제작 HTML의 20회·1,000문항을 추가한다. 기존 교재 HTML의 내장 50문항과 폐기된 과거 모의고사는 포함하지 않는다.

## 콘텐츠 계약

- 원본: `content-source/mock20-20261109.html.gz` (사용자가 첨부한 HTML 그대로 압축).
- 원문 SHA-256: `6184a2dec1b82fbf850004ae309fe5c373dd5a8e42e099c0a5d4a608a03320b1`.
- 통합 버전 `textbook.20261109.2`, 이론 버전 `.1` 유지, 시험 버전 `mock20.20261109.1`.
- `npm run content:build-textbook`가 두 원문을 해시 검사 후 결정적으로 변환한다. 변경된 원문은 자동으로 승인하지 않는다.
- 회차 ID `SQLD-M01`~`SQLD-M20` 유지, 새 문항 ID `ME20261109:<원문ID>`, 교재 연결 `TB20261109:<절ID>`, 출처에는 별도 네임스페이스 사용.
- 지문·SQL·표·보기·정답·보기별/전체 해설·결과 표 660개·해설 표 20개·출처·작성자 검산 데이터를 보존한다. 작성자 검산 기록은 독립적인 DBMS 실행·전문가 검수를 의미하지 않는다.

## 응시와 복습

홈 / 교재 / 문제풀이 / 실전 / 기록의 5개 네이티브 탭을 제공한다. 회차당 1과목 10문항 + 2과목 40문항, 문항당 2점이며 총점 60점·과목별 40%를 연습 기준으로 사용한다.

실전 모드는 90분, 학습 모드는 시간 제한이 없다. 두 모드 모두 최종 제출 전에는 정답·해설을 제공하지 않는다. 동시 진행은 한 회차만 허용한다. 답안표·검토 표시·답안 지우기·재시작 복구를 지원한다. 시간 변경으로 실전 시간이 늘어나지 않는다. 제출과 저장은 직렬 처리하고 스냅샷은 응시 시작 시 고정한다.

제출 결과는 전체/오답·미응답/검토 표시로 필터링하며 문항별 지문·표·SQL·내 답안·정답·모든 해설·관련 교재·출처를 표시한다. 같은 회차 재응시 중에는 과거 결과 및 저장/복습 경로에서도 해설과 메모를 차단한다.

오답 목록은 모드를 합친 회차별 마지막 제출을 기준으로 한다. 복습에서 확실히 정답을 제출하면 목록에서 제외하고, 재응시에서 다시 틀리거나 미응답이면 복원한다. 과거 점수는 수정하지 않는다. 실전/학습 평균은 각각 회차별 최근 기록으로 집계한다. 일반 340문항 학습 지표에 모의고사 복습 기록을 섞지 않는다. 응시 이력은 10개로 자르지 않으며 더 보기로 표시한다.

저장 문항과 명시적으로 저장하는 문항별 메모(10,000자 한도)는 기기 SQLite에만 남는다. 백업·가져오기·내보내기·인쇄·PDF·서버 동기화는 추가하지 않았다.
