# 0.5.0 모의고사 재편과 학습 UI

소유자는 기존 1권과 관련 응시·진행 중 시험·저장·메모·권한까지 삭제하는 방안을 선택하고 구현을 지시했다. 기존 2권은 새 1권(1~20회), 기존 3권은 새 2권(21~40회)로 표시한다. 각 권 첫 5회, 총 10회가 무료다. 내부 SQLD-M21~60 및 MEV2/MEV3 식별자와 남기는 원문·응시 스냅샷은 유지한다. 교재 216절과 일반 연습 340문항은 변경하지 않는다.

작업은 콘텐츠, 선택적 기록 이관/광고 권한, 문제를 먼저 보여주는 해설, 선택 영역, 통합/출시의 5개 PR로 나눈다. `mockCatalog: curated40`를 최종 통합에서만 활성화한다. 기존 60회 팩과 출처는 테스트·이관 회귀 검사에 보관한다.

새 콘텐츠는 textbook.20261112.2 / mock40.20261112.1이다. 삭제한 1권에 해당하는 current/previous 상태와 별도 스냅샷만 원자적으로 정리하며 실패하면 전부 롤백한다. 이전 권한을 새 문제에 옮기지 않는다. 새 1~5회/21~25회는 무료이고 나머지 30회는 회차별 earned reward 한 번으로 두 모드·재응시·해설에 계속 접근한다.

해설은 한 문항씩 문제·자료·보기·내 답/정답·해설·보기별 근거 순으로 표시한다. 권 탭과 분량 선택은 일반 이동 버튼과 구별한다. Native UI, 큰 글자, 제출 전 해설 차단, 중지와 광고 억제를 유지한다. 승인 해시와 실제 검증 범위를 따로 기록하며 0.4.0의 iOS 검증 예외를 재사용하지 않는다.
