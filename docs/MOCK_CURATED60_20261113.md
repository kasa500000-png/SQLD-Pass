# 0.6.0 새 3권 추가

소유자가 첨부 전체20회·1,000문항을 선택하고 구현을 지시했다. 현재1·2권40회를 그대로 유지하며 원본Vol.4(61~80회)를 앱의3권41~60회로 추가한다. 내부vol4/SQLD-M61..80/MEV4 식별자를 쓰며 기존vol2/3 및 M21..60은 바꾸지 않는다. 교재216절·일반연습340문항·37개도구는 유지한다.

각 권 첫5회(표시1~5·21~25·41~45)는 무료, 나머지45회는 회차별 earned reward 한 번으로 두 모드·재응시·해설을 이용한다. 기존 플랫폼별 광고 단위·성인 이용 안내·UMP·진행 중 전역 광고 억제·90분 실제 풀이 시간과 명시적 재개는 유지한다.

## 콘텐츠와 기록

- 원본SHA-256: `0946e1889342b912c6528ae1a1897e361bd6aa3cade490cbda1cec28c5834f25`. JSON만 읽고 HTML 실행코드·저장·백업·인쇄는 앱에 넣지 않는다. 중복 이론은 기존 교재에 연결한다.
- 신규 콘텐츠 `textbook.20261113.1` / `mock-curated60.20261113.1`은 과거 다른60회 팩과 구분한다. 과거60회/현재40회 생성 결과를 보존한다.
- 현재40회에서 모든 기록/이전SQLite슬롯/불변스냅샷을 보존한다. 이전 교재에서 직접 업데이트할 때만 폐기한 원본1권과 연결 기록/권한을 양슬롯·스냅샷에서 원자적으로 정리한다. 재실행 시 중복 정리나 안내 재표시를 하지 않는다.
- 원문 내용·보기별 해설·계산 결과·작성자 검산 주석은 그대로 보존한다. 저자의 검산 주장, 앱 원문 대조, 실기기 검증, 소유자 내용 검수는 서로 다른 증거다.
