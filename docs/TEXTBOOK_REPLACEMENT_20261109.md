## 네이티브 학습

홈 / 교재 / 문제풀이 / 기록의 네 탭을 사용한다. Part → Chapter → Section 목차, 본문 검색, 읽던 위치, 절 저장, 읽음 완료, 장별·종합 문제, 오답·헷갈림 복습, 카드 앞뒤와 알고 있음, 용어 연결, 원문 출처·범위를 제공한다.

읽음 수 / 풀어본 고유 문제 수 / 문제별 마지막 답안 정답률을 분리한다. 검색에는 이론·SQL·용어만 넣고 문제의 정답·해설은 넣지 않는다. 목표일이 있으면 남은 절 수 / 남은 일수의 올림으로 하루 분량을 배정하고, 없으면 다음 미학습 절을 배정한다. 같은 날에는 배정을 저장해 읽음 완료 시 분량이 계속 바뀌지 않는다. 목표일 변경과 다음 날 첫 실행 시 다시 배정한다. 읽기 예상 시간을 임의로 생성하지 않는다.

7가지 블록을 네이티브 Text / Table / Code / Disclosure / Flow / Callout / Widget으로 표시한다. 표·SQL은 가로 스크롤과 줄바꿈을 지원한다. 원문의 37개 도구를 빌드 시 유한 상태 그래프(271 상태)로 컴파일한다. 학습 시에는 네이티브 버튼으로 상태를 선택하며 HTML, WebView, eval, DB 연결을 사용하지 않는다. 선택된 표 셀, 문자, 스키마 카드, 상태 설명과 SQL 결과를 보존한다. 도구 상태는 해당 화면에 머무는 동안만 유지하며 초기화할 수 있다. 실제 DBMS 실행 또는 모든 SQL의 제품별 검증을 의미하지 않는다.

## 한 번만 수행하는 기록 전환

기존 `phase1.20260908.1`을 새 버전으로 업데이트할 때, 구문항을 새 문항으로 연결하지 않는다. 구버전 진행 중 연습·시험 검증보다 먼저 전환한다. 권한 형식 또는 설정이 손상되거나 알 수 없는 버전이면 삭제하지 않고 중단한다.

삭제: 읽음, 북마크, 컬렉션, 읽던 위치, 날짜별 학습 활동·진도, 답안·복습, 진행 중 연습·풀이 결과, 모든 시험 시도·답안·점수·스냅샷.

보존: 온보딩 완료 상태, 목표일·학습 시간·주간 목표·테마·글자 크기, 별도 알림 저장소, 기존 권한 지갑. 오래된 시도의 기존 이용 권한은 시도를 지우기 전에 이관한다. 미완료 광고 요청은 보상으로 인정하지 않는다.

SQLite exclusive transaction 안에서 새 current 저장과 previous·exam_snapshot 삭제를 함께 수행한다. 저장 실패 시 모두 롤백한다. 성공 후 전환 안내를 보여 주며 확인 상태도 저장한다. 전체 삭제는 기존처럼 명시적 사용자 동의로 수행한다. 다시 설치하거나 기기를 바꿨을 때 로컬 권한을 복원한다고 약속하지 않는다.

## 공개 배포 전

과거 `release/CONTENT_REVIEW_STATUS.json`, `release-approval.json`, 광고 승인 문서를 새 콘텐츠 승인으로 바꾸지 않았다. 새 콘텐츠 해시·범위에 대한 검수 완료와 해당 빌드의 실제 검증을 기록해야 공개 출시 게이트를 통과한다. 원문이 기록한 DataQ 확인 실패 및 DBMS 실행 범위는 그대로 보존하며 공식 검수 완료로 주장하지 않는다.
