# iOS 0.6.0(17) 배포 실행 기록

## 승인과 실행 범위

소유자가 현재 iPad 이용 불가와 Android 정식 제출 상태를 안내받은 뒤 **“이번에도 예외 진행”**을 지시했다. 이 지시는 0.6.0(17)의 추가 iPad 실기기·iOS 동의 재검증에만 적용한다. 두 검사는 **미수행**이며 통과로 기록하지 않는다. 0.5.0의 예외를 재사용하지 않았다. 런타임 동의·성인 광고 이용 조건·보상 완료 이벤트·서명·콘텐츠 승인 검사는 유지했다.

콘텐츠는 `textbook.20261113.1`, SHA-256 `61316063d2112c7b5cd25773a662a61b9037925e375073131c094d2522ca9fd5`다. 소유자의 직접 검수 확인은 “새 3권 내용 검수 완료”이며 새 3권을 포함한 60회·3,000문항이다. 교재 216절·일반 연습 340문항, 기존 학습 기록과 권한은 변경하지 않았다. 각 권의 첫 5회는 무료다.

소스는 `aa93d4ed80f5bd6d7492d19063b251f6faea8177`의 런타임 코드다. 이번 변경은 승인·제출 증거와 스토어 메타데이터이며 런타임 코드를 변경하지 않았다.

## 스토어 설명과 이미지

60회·3,000문항, 권별 첫 5회 무료, 나머지 45회 선택형 보상 광고, 기존 40회 기록 보존을 한국어 설명·업데이트 노트·심사 메모에 반영했다. 현재 광고 SDK·데이터 수집·추적 동작은 바뀌지 않아 기존 개인정보 신고와 연락처를 유지했다.

스크린샷은 이번 0.6.0의 별도 테스트 앱을 새 iPhone 14 Plus / iPad Pro 13 M4 시뮬레이터에서 실행해 캡처했다. 홈·교재·문제·각 1/2/3권을 포함한 기기별 6장이다. 크기는 iPhone 1284×2778, iPad 2064×2752다. 캡처 중 광고를 요청하지 않았다. 이미지 업로드 시 기존 5장과 새 6장이 합계 10장 제한을 넘겨 마지막 추가가 거절되었고, 새 이미지 각각의 COMPLETE를 확인한 뒤 대응하는 구버전 이미지를 교체하는 방식으로 처리했다.

[메타데이터](evidence/ios-release-060-20261113/metadata.json). 이는 캡처·등록 증거이며 물리 기기·동의 재검증을 대신하지 않는다.

## 기존 검증과 미수행 항목

현재 후보의 Android 실기기·EEA·보상, iOS 시뮬레이터 UI·SQLite 비교·공식 테스트 보상, 489개 자동 테스트와 native 빌드는 [통합 검증 기록](MOCK_CURATED60_20261113.md)을 따른다. 최초 iOS EEA 요청 실패 화면을 동의 폼 표시 성공으로 세지 않는다. 이후 실제 표시된 수락·철회만 증거로 사용한다.

추가 iPad 실기기·iOS 동의 재검증은 이번 예외에 따라 미수행이다. 모든 60회 완주, 전체 VoiceOver 탐색, DBMS별 모든 정답 검산도 수행했다고 주장하지 않는다.

기존 지원 사이트의 0.6.0 문안 배포는 Sites 인증 방식 불일치로 완료되지 않았다. 기존 privacy/support 링크는 유지되며 새 개인정보 수집 동작은 없다. 사이트 갱신을 완료로 기록하지 않는다.
