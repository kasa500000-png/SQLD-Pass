# 새 교재·UI 업데이트용 스토어 문안 초안

공개 전 실제 버전·최종 광고 모드·새 콘텐츠 검수 승인과 대조한다. 아직 게시하지 않았다.
권장 표시 버전: 0.3.0. 빌드 번호는 각 스토어의 현재 최대 번호 조회 후 정한다.

## 이번 업데이트

- 새 학습 교재: 5개 Part, 18개 장, 216개 절
- 장별 확인 문제 268문항과 종합 연습 72문항
- 별도 제작 모의고사 20회, 총 1,000문항
- 90분 실전 모드와 시간 제한 없는 학습 모드
- 시험 중 고정 타이머·답안표·문항 이동, 제출 후 결과와 해설 탐색 개선
- 오답 복습, 문항 저장, 기기 내 메모 및 학습 기록
- 큰 글자와 iPad 화면 구성 개선

## 업데이트 시 기록 안내

기존 60레슨 교재에서 새 교재로 전환할 때 이전 콘텐츠에 연결된 진도·답안·저장 목록·
복습·모의고사 기록은 한 번 정리됩니다. 설정·학습 알림·기존 회차 이용 권한은 유지됩니다.
이미 새 교재 버전을 사용하는 경우 새 교재 학습 기록은 유지됩니다.

## 설명에 사용할 핵심 사실

회원가입 없이 기기 안에서 학습합니다. 이론·표·SQL 예제와 37개 네이티브 체험 도구로
개념을 확인하고 문제를 풀 수 있습니다. 체험 도구는 고정 예제를 보여주며 실제 DBMS에
SQL을 실행하지 않습니다. 두 모의고사 모드는 최종 제출 후 정답과 해설을 제공합니다.
학습 모드와 실전 모드의 기록을 구분합니다. 공식 기출문제 또는 시험기관 공식 앱이
아니며 실제 합격을 보장하지 않습니다.

앱 삭제·전체 데이터 삭제·기기 변경 시 로컬 기록과 권한은 복구할 수 없습니다.
계정·클라우드 동기화·결제·원격 학습 분석을 추가하지 않았습니다.

광고 관련 문안은 최종 활성화 모드와 독립 QA가 확정된 후 기존 개인정보 신고와 대조합니다.
현재 내부 검증 빌드는 광고 OFF입니다.
