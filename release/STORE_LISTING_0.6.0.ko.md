# 0.6.0 스토어 문안

현재0.6.0 제출 준비 문안이다. 콘텐츠 검수·현재 플랫폼별 검증 이후 제출하며 아직 스토어에 반영하지 않았다.

## 간단한 설명

SQLD 교재 216절, 확인 문제와 60회 모의고사로 개념부터 실전까지 공부하세요.

## 상세 설명

SQLD Pass에서 교재 순서대로 개념을 익히고 문제와 모의고사로 이해를 확인하세요.

■ 교재 5개 Part · 18개 장 · 216개 절

데이터 모델링, SQL 기본·활용·관리 구문과 핵심 정리를 학습합니다. SQL 예제, 데이터 표와 37개 네이티브 체험 도구를 제공합니다. 체험 도구는 고정 예제를 설명하며 실제 DBMS에 SQL을 실행하지 않습니다.

■ 확인 문제와 짧은 연습

장별 확인 문제 268문항과 종합 연습 72문항을 제공합니다. 5·10·20문항 또는 전체 연습을 선택하고 답안 확인 후 해설을 읽으세요.

■ 모의고사 3권 · 60회 · 3,000문항

회차당 50문항을 90분 실전 모드 또는 시간 제한 없는 학습 모드로 풉니다. 두 모드 모두 최종 제출 후 정답과 해설을 제공합니다. 해설에서는 문제·자료·보기와 내 답을 바로 확인하며 공부할 수 있습니다. 오답 복습·문항 저장·메모를 지원합니다.

실전 모드는 실제 풀이 시간을 기준으로 합니다. 일시정지하거나 앱을 벗어나면 답안과 남은 시간을 저장하고, 돌아와서 이어서 풀기를 눌러 재개합니다. 진행 중 시험은 한 번에 하나입니다.

■ 무료 학습과 선택형 광고

교재·확인 문제·복습과 각 권 첫 5회(1~5회·21~25회·41~45회)는 광고 없이 무료입니다. 나머지 회차는 회차별 보상형 광고를 한 번 완료해 저장하면 해당 기기에서 만료 없이 두 모드·재응시·제출 후 해설을 이용할 수 있습니다. 만 18세 이상 광고 이용 조건과 지역별 동의 절차를 적용합니다. 광고를 이용하지 않아도 무료 학습과 이미 열린 회차는 이용할 수 있습니다.

작은 배너는 홈과 기록 화면에만 표시합니다. 진행 중 또는 일시정지한 모의고사가 있으면 다른 화면에서도 광고를 표시하지 않습니다. 추적 허용이나 광고 클릭·설치는 회차 해제 조건이 아닙니다. 인터넷 연결·동의 상태·광고 제공 여부에 따라 광고를 이용할 수 있습니다.

■ 0.6.0 업데이트 안내

새 3권 41~60회 1,000문항을 추가했습니다. 현재 1·2권 40회와 학습 기록·진행 중 시험·저장 문항·메모·열린 회차를 유지합니다. 0.5.0 이전의 구성을 쓰는 경우에는 기존 안내에 따라 폐기한 원본 1권과 그 연결 기록만 정리하고, 나머지 교재·일반 연습·모의고사 기록을 보존합니다.

■ 회원가입 없이 기기에 저장

학습 기록과 회차 이용 권한은 기기 내부에 저장합니다. 계정·클라우드 동기화·앱 내 결제·구독은 없습니다. 앱 삭제·전체 데이터 삭제·기기 변경 시 로컬 기록과 이용 권한을 복원할 수 없습니다.

SQLD Pass는 독립적으로 제작한 학습 앱으로 시험 주관기관의 공식 앱이 아니며 공식 기출문제를 제공한다고 표방하지 않습니다. 연습 점수와 모의고사 결과는 실제 시험 합격을 보장하지 않습니다.

## 심사 메모

로그인·회원가입·결제가 없습니다. 새 설치에서는 실전 탭의 1~5회, 21~25회와 41~45회가 무료이며, 6~20회, 26~40회와 46~60회는 선택형 보상 광고로 열립니다. 이용자는 응시 안내의 만 18세 이상 이용 안내를 읽고 광고 버튼을 직접 누릅니다. 지역에 따라 UMP 개인정보 동의 화면이 표시됩니다. 보상 완료 이벤트로만 해제하고 광고 클릭·설치나 ATT 추적 허용을 요구하지 않습니다. 광고는 비개인화·제한 설정을 사용하며 IDFA·게시자 퍼스트 파티 ID를 사용하지 않습니다.

해제 후 사용자가 모드를 선택해 시험을 시작합니다. 답안은 제출 전까지 바꿀 수 있으며 최종 제출 후 문제와 해설을 바로 볼 수 있습니다. 진행 중 모의고사가 있으면 모든 화면에서 광고를 억제합니다. 이 버전은 현재1·2권을 유지하며 새3권을 추가합니다. 구버전에서 직접 업데이트하는 경우 폐기한 원본1권의 기존 정리 정책을 한 번 적용하며, 현재40회 기록은 유지합니다.
