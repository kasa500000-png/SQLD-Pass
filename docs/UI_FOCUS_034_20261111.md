# 0.3.4 학습 집중 UI 개선

소유자는 2026-11-11 Android 0.3.3 실기기 100장 점검의 권장 개선을 작업별 PR·커밋으로 반영하고 양쪽 스토어 최종 출시까지 진행하도록 위임했다. 콘텐츠 textbook.20261109.2와 20회 모의고사만 사용하며 추가 21–60회는 보류한다.

## 작업 단위

1. 기록 읽기 실패 시 연결 재생성과 재시도. 실패한 저장을 성공으로 표시하거나 데이터를 초기화하지 않는다.
2. 실전·연습 풀이: 질문과 보기 공간 우선, 검토를 질문 가까이, 간결한 상태와 집중 내비게이션.
3. 해설·복습·저장: 정오 비교와 해설 우선, 원문 접근 유지, 간결한 목록과 문항 도구.
4. 교재·표: 읽기 우선 행동, 목차/앞뒤 절 정리, 표 표시와 실제 확대 의미 개선.
5. 홈·탐색·사전·카드: 이어 학습 우선, 짧은 통계, 검색 지우기·필터 통합, 반복 설명 제거.
6. 결과·기록: 점수/정오/중지 정보를 묶고 최근 결과를 쉽게 찾게 한다. 집계 정의와 이전 점수는 변경하지 않는다.
7. 설정: 변경 시 저장 활성, 저장하고 이동/저장하지 않고 이동/계속 설정의 명확한 선택.
8. 잠긴 회차: 회차 선택과 광고 실행을 구분하고 안내·파란 버튼 반복을 줄인다. 매 시청의 보상·성인 안내와 명시적 선택, UMP, earned-event-only 지급은 그대로다.
9. 통합 native QA·업데이트 보존·광고/동의 증거·실제 빌드·TestFlight·양 스토어 정식 제출.

## 공통 기준

기존 semantic palette와 17/28 본문, 18/29·600 질문, 16/26·400 보기를 유지한다. 본문 대비나 터치 크기를 줄이지 않고 반복 메타/설명/카드/버튼부터 정리한다. 기본 5개 탭을 유지하되 풀이 중은 집중 탐색을 사용한다. 주 행동 하나, 중립 보조 행동, 연한 선택 상태, 의미 있는 정오 색상과 문구를 적용한다. 펼침과 새 화면 이동 아이콘은 구분한다.

2026-11-11 pause 계약은 그대로다. 중지와 백그라운드는 시간을 멈추고 명시적 재개가 필요하다. paused도 active이므로 광고/추가 응시/해설 게이트가 유지된다. 답안·점수·본문·ID·SQLite ordered writes·immutable snapshots·기존 권한은 바꾸지 않는다.

## 검증과 출시

각 PR은 관련 상태 회귀 검사와 타입 검사를 기록한다. 통합 후보에서 실제 Android/iOS 빌드와 대표 기기 조작을 확인한다. 0.3.3(13)의 iOS 실기기 생략 예외는 0.3.4에 재사용하지 않는다. 심사 제출은 공개 출시 완료와 구분하고, 승인 후 자동 출시 및 서버 상태를 기록한다.

기록 복구는 실제 초기화 실패 후 같은 DB 파일/두 슬롯/스냅샷을 그대로 읽는지 검증한다. Expo의 `useNewConnection` 옵션은 기존 캐시와 별도의 연결을 연다([공식 SQLite 문서](https://docs.expo.dev/versions/latest/sdk/sqlite/#sqliteopenoptions)). 초기 native NPE의 최초 발생 원인·빈도를 확정한 것으로 표현하지 않는다.
