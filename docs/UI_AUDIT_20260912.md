## 구현 경계

polishLearning은 기존 renderMonetized가 구성한 화면을 보완하는 표현 계층이다.
광고 권리는 기존 hasAccess/offerUnlock을 사용하고, EARNED_REWARD·재시도·광고 중 버튼 잠금을 유지한다.
기존 보상 저장 재시도 버튼과 광고 개인정보/전체 삭제 안내를 보완 화면에서도 보존한다.
해설은 답안 제출 후에만 표시한다. 모의고사 해설은 저장된 응시 스냅샷에서 읽는다.
SQL을 실행하거나 HTML을 평가하지 않는다. 런타임 AI·새 서버·외부 UI 의존성을 추가하지 않는다.

## 원고 점검 결과와 남은 편집 작업

보관된 원본에는 60레슨/120확인문제/1,000모의문항이 있다. 모든 확인 문제에 전체 해설은 있으나
120개 확인 문제의 구조화된 보기별 해설 필드는 비어 있다. 모의고사 1,000문항에는 해당 필드가 있다.
이번 UI 작업은 없는 해설을 만들어 채우지 않는다. 추가 집필·독립 감수는 별도 콘텐츠 버전 작업으로 처리한다.
정답의 학술적 타당성·시험 범위·난이도를 검증 완료한 것으로 표시하지 않는다.

## 중요한 기존 이관 상태 정정

기준 main의 실제 트리는 content-pack/content.json.gz 없이 11개 부분 base64 파일과
빈 generated/content.json만 포함한다. PR #3 설명과 이전 업로드 완료 안내는 실제 트리와 일치하지 않는다.
이번 검사에는 대화에 보관된 원본 runtime을 사용했다. 전체 gzip Git 이관 완료를 주장하지 않는다.
이 UI 변경은 콘텐츠 반입 차단이나 공개 승인/광고 활성화 차단을 해제하지 않는다.
