# 핵심 노트와 고정 복귀 개선

승인된 구현 범위: 5개 기본 탭의 고정 상단에 핵심 노트 진입을 추가한다.
풀이 중 화면에는 추가하지 않는다. 7분류·83노트(필수45, 예제70)와 빠른 암기12줄을
네이티브로 제공한다. 분류별 연속 읽기, 전체/필수/저장 필터, 전체 내용 검색,
노트별 저장과 읽기 위치 복원을 제공한다. 읽음을 학습 완료나 정답률에 합산하지 않는다.
기존 핵심 카드와 용어 사전은 유지한다. 노트 화면에는 광고를 표시하지 않는다.

## 작업 단위

1. 원본 압축 보관, 해시 고정, DOM 가져오기, 검토된 문구 수정, 독립 후보 검사.
2. 노트 탐색·읽기·검색·저장·복원과 호환 이관. 기존 학습·광고 권한은 그대로 보존.
3. 결과에서 연 해설은 상단 고정 `결과`로 복귀. 다른 경로는 원래 복귀와 결과 접근을 분리.
4. 통합 콘텐츠 활성화, 실제 QA, 출시 설정·기록. 예정 앱0.7.0.

콘텐츠는 textbook.20261113.2 / memory-notes.20261113.1.
교재216절·일반연습340문항·실전60회3000문항, 이론·모의고사 버전과 식별자는 변경하지 않는다.
원래1권은 복구하지 않는다. 이전 버전 직접 업데이트의 기존 선택적 폐기 규칙만 유지한다.
양쪽 SQLite 슬롯, 제출 스냅샷, 일시정지, 광고 해제 권한을 보존한다.
