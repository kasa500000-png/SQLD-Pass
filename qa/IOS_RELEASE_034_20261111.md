# iOS 0.3.4(14) 출시 준비 기록

2026-11-11 22:14 KST. 소유자는 TestFlight 업데이트와 정식 제출을 재차 지시했다. 제출 실행 권한은 확보되어 있으며 추가 배포 승인을 요청하는 상황은 아니다.

## 수행한 작업

- Apple API에서 현재 공개 버전0.3.3(13), 새0.3.4 초안 `PREPARE_FOR_SUBMISSION`, 승인 후 자동 출시 `AFTER_APPROVAL`을 확인했다.
- 새 기능 설명, 교재·광고 설명과 심사 메모가0.3.4(14)에 맞는지 확인했다. 기존 개인정보 신고·스크린샷·심사 연락처를 유지했다.
- Google Drive의 암호화 백업에서 서명 자료를 복구하고 백업 해시·배포 인증서·프로비저닝을 확인했다. 비밀 자료는 저장소에 포함하지 않았다.
- iPad가 다시 연결되어 별도 공식 테스트 광고 앱0.3.4(14), `com.sqldpass.app.internal`을 설치했다. 운영 앱과 기존 학습 데이터를 초기화하지 않았다.
- 물리 기기 XCTest 실행기를 빌드·서명했다. 기기가 잠긴 상태로 실행 대기한 뒤 `Lost pending connection to the test runner before launch`로 종료됐다. 앱의 학습·광고 동작 검사는 시작되지 않았다.
- 운영 archive/export/upload, TestFlight 기존 내부 그룹 추가 및 새 버전 정식 심사 전송 절차를 준비했다. 아직 실행하지 않았다.

## 검증 범위와 남은 작업

기존436개 자동 검사, Android 실기기와 iOS 시뮬레이터 결과는 [통합 보고](UI_FOCUS_034_20261111.md)에 있다. 이번 iPad 설치 성공은 실기기 동작·광고·동의 검사 통과를 의미하지 않는다. 현재 코드의 iOS 광고 승인 증거를 새로 발급하지 않았으며 기존 Android 승인 파일도 변경하지 않았다.

잠금 해제 후 현재 빌드의 중지·재개·최종 제출·기록 유지와 공식 테스트 광고·동의 경로를 확인하고, iOS 승인 증거를 기록한다. 이어 운영 빌드14의 archive/export, Apple 업로드 처리, TestFlight 내부 그룹 추가, App Store 정식 심사 제출을 수행한다.

`AGENTS.md`의 “This exception does not authorize skipping validation for future versions.”에 따라0.3.3의 검증 생략을0.3.4에 전용하지 않는다. 이번 버전의 새 생략 지시는 아직 받지 않았다. 미실시 검사를 통과로 기록하지 않는다.
