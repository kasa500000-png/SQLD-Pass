## 광고와 실행 환경의 한계

- 내부 검사는 공식 Google 테스트 광고 단위만 사용했다. 운영 노출/클릭이나 수익을 검증하지 않았다.
- iOS 시뮬레이터21회는 공식 테스트 광고 뒤 해제 및 재실행 후 유지,41회는 테스트 광고를 닫은 뒤 해제를 확인했다. evidence/iphone/18~23. 최초 러너는 광고 문구/닫기 요소를 잘못 예상해 실패했으며, 실제 관찰된 Close 버튼으로 후속 검사는 통과했다. 실패한 전체 suite를 통과로 바꾸지 않는다. 권 탐색 XCTest는 iPhone/iPad 각각 통과했다.
- Android UI 자동화는 실제 접근성 트리에서 좌표를 계산했다. UIAutomator 연결 끊김 및 스크롤 관성으로 일부 러너가 실패했고 관찰 후 재연결/안정화하여 재개했다. 학습 데이터나 보상을 주입하지 않았다.
- iOS 물리 기기는 연결 불가였고 소유자는 Android만 연결해 그 기기로 진행하도록 답했다. iOS0.4.0 물리 광고·동의 검사는 미실행이다.0.3.3/0.3.4 검증 생략 예외를 전용하지 않는다.
- AdMob 두 앱 준비됨/광고 게재 사용 설정됨, 두 배너 자동 새로고침 사용중지됨을2026-11-12 다시 확인했다. `evidence/mock60-20261112/admob-*.{json,txt}`.
- Google Play0.3.4(20)는100% 출시됨, App Store0.3.4는READY_FOR_SALE. 이 상태를0.4.0 출시 완료로 해석하지 않는다. Play는 기존 DEX 난독화0%에2027년2월 해결 기한과 넓은 화면 API 권고를 표시했다. 이번 콘텐츠 변경에서 빌드 최적화 설정을 바꾸지 않았다.

- 물리 SM-F721N에서21·40·41·60회 공식 테스트 광고의 리워드 완료와 해당 회차 해제를 확인했다.60회는 보상 전 프로세스 종료 후 잠금 유지, 다시 끝까지 시청한 후 실전/학습 시작 버튼을 확인했다.21회와40·41회 권한은 여러 차례 앱 재실행과 진단 APK 업데이트 뒤에도 유지했다. 03~04,15~24번 캡처.
