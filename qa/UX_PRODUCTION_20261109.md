## 구현

- P1: 첫 화면 모드 선택과 고정 시작 버튼, 시험 상단 상태와 하단 이전/답안표/다음, 저장 후 나가기 확인. 시험·답안표에서는 전역 탭과 설정을 숨긴다.
- P1: 결과 요약과 문항 해설을 분리하고 해설 필터·문항 선택·결과 복귀를 제공한다. 점수와 제출 당시 스냅샷은 변경하지 않는다.
- P1: 주요 행동/보조 행동/목록/선택지/삭제 버튼을 구분한다. 정답·내 답은 색상과 문구로 함께 표시한다.
- P1: 알림 예약 실패를 진단했다. 서명하지 않은 시뮬레이터 빌드에서 Expo 알림 초기화의 Keychain 접근이 실패했다. Xcode의 정상 시뮬레이터 서명으로 수정했고, 알림 권한 허용 → 예약 → 끄기를 확인했다. 초기화나 권한 절차를 우회하지 않았다.
- P2: 홈의 중복 학습 링크 정리, 실제 오답 기반 복습, Part별 접기·장 목록 정렬, 본문 하단 학습 행동 고정, 5/10/20/전체 연습, 간결한 모의고사 목록과 상태 필터, 균일 답안표, 최근 응시 기록 우선 배치.
- P2: iPad 홈·목차의 반응형 두 열 구성, 좁은 폭·큰 글자에서 한 열, 설정 선택 UI·미리보기·저장 후 원래 화면 복귀, 읽기 폭 제한, 모달 안전 영역과 상단 닫기.
- P3: 핵심 카드 미숙지 필터, 용어 출처 맥락, 빈 상태 안내, 접을 수 있는 메모 편집과 저장 표시, 도움말 개선.
- Expo 권장 패치 8종 및 lockfile 갱신. shell-quote 취약 버전도 갱신했다. 콘텐츠 원문·문항·정답·해시와 저장소 마이그레이션 정책은 유지했다.
