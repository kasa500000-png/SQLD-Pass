# 0.4.0 모의고사 2·3권 추가

소유자가2026-11-12 확정 계획의 구현을 지시했다. 기존216절·340문항·37개 도구와1~20회를 유지하고21~60회를 추가한다. 권 탭과 통합 필터를 사용하며 다음 회차 추천은 추가하지 않는다. 콘텐츠/기록·권한/실전/기록·복습/통합·출시의5개 PR로 분리한다.

## 콘텐츠 계약

- 기존0.3.4 콘텐츠 해시 `1f7a60245d9b75a19ad733dca7fc281539d73ebdc0fcfa25fd5a959ebd7d589d`를 테스트 전용 fixture로 보존한다. 앱 진입점은 이 fixture를 가져오지 않는다.
- 신규2권 원문 SHA-256: `e6fef8f1291a784af1fa21f0c2d65641afa96c454c9ea7bfa971402114e296fb`.
- 신규3권 원문 SHA-256: `9a1c36c857d03e75398f467e9eef95af8568eb9811a3042db4a71461ed1f6979`.
- 원문 HTML의 JSON만 읽으며 페이지의 실행 코드·웹 저장소·백업·인쇄를 앱에 도입하지 않는다. 내장된 중복 이론 대신 기존 교재 절을 참조한다.
- 회차는 `SQLD-M21`~`SQLD-M60`, 문항은 `MEV2:`/`MEV3:` 네임스페이스다. 주제·출처도 권별로 분리한다. 기존1권 객체와 ID는 변경하지 않는다.
- `mockPack.volumes`는 권의 회차·주제·출처와 작성자 주석을 연결한다. 응시 스냅샷에 새 필드를 의무화하지 않는다.
- 통합 `textbook.20261112.1` / 시험 묶음 `mock60.20261112.1`, 이론과1권 개별 버전은 유지한다.
- 통합 후보 해시 `ef14277859237b0a08f5f8b0857e37ff26587cdc0aff6b5d21527787870a1db3`,9,413,256bytes,60회·3,000모의문항·340일반문항·216절.

## 단계적 활성화

`content-pack/build-target.json`의 권 수가1인 동안 운영 팩은 바뀌지 않는다. 후보는 `build(root,{mockVolumes:3,outputRoot:...})` 또는 `write:false`로 생성한다. PR1~4의 화면·기록 처리는1권 팩도 지원한다. 최종 통합 PR에서만3권 팩을 활성화한다.

기존 버전의 콘텐츠 승인과 iPad 검증 예외를 새 버전에 전용하지 않는다. 새 콘텐츠의 직접 검수 완료 확인, 실제 native/consent 검증, 콘텐츠·광고·서명 게이트를 각각 기록하고 TestFlight와 양 스토어 프로덕션 제출을 수행한다. 진행 중 시험의90분 실제 풀이 시간·명시적 재개·불변 점수와 SQLite의 순서 있는 저장은 그대로 유지한다.

2026-11-12 소유자는 위 통합 버전·해시를 제시한 질문에 “새 2·3권 내용 검수 완료”라고 답했다. 이 확인은 `release/CONTENT_REVIEW_STATUS.json`에 기록했다. 원문 검산의 전문 감수 여부나 제공되지 않은 검수 일시는 추정하지 않는다.
