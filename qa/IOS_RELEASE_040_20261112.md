# iOS 0.4.0(15) 출시 기록

## 소유자 지시와 검증 범위

소유자는 0.4.0의 iPad·동의 검증 및 TestFlight·정식 제출 미완료 상태를 안내받고 “ios도 별도 검증 생략 후 진행”이라고 지시했다. 이번 버전에 한해 추가 물리 iPad 및 지역별 iOS 동의 재검증을 생략한다. 미실행 검사를 통과로 표시하지 않는다. 기존 0.3.3·0.3.4 예외를 재사용하지 않았으며 [AGENTS.md](../AGENTS.md)에 새 한정 예외를 기록했다.

기존 458개 자동 검사, Android 실기기, iPhone·iPad 시뮬레이터 및 서명 내부 빌드 결과는 [60회 검증 기록](MOCK_VOLUMES_20261112.md)에 있다. 시뮬레이터·Android 결과는 물리 iPad 검증이 아니다. 이번 제출 작업은 앱의 기능·런타임 동의·earned-only 해제 조건·기록 구조를 변경하지 않았다.

## 배포 준비와 아티팩트

- Apple API에서 현재 공개 0.3.4와 업로드 빌드14의 VALID를 확인한 뒤 0.4.0(15) 초안을 생성했다. 승인 후 자동 출시 `AFTER_APPROVAL`이다.
- Google Drive의 기존 암호화 백업을 인증 복호화하고 iOS 서명에 필요한 파일만 임시 복원했다. 현재 프로비저닝의 앱 ID·팀·유효기간(2027-10-03)과 배포 entitlement를 확인했다. 비밀 자료는 Git에 포함하지 않는다.
- 이번 소유자 예외·실행 증거·미실행 범위를 분리한 [iOS 광고 승인](../release/history/ads-release-approval.ios.mock60-20261112.json)을 현재 코드 해시에 연결했다. Android 승인 이력은 유지한다.
- 운영 Release archive 및 App Store export 성공. archive와 내보낸 IPA 코드 서명 검증, 배포 앱 ID `com.kasa500000.sqldpass`, 0.4.0(15), `get-task-allow=false` 확인.
- IPA 19,546,937바이트, SHA-256 `a0959cb79314ef23b400dd1df2c4efb6018d5c6a6d7530033246e36230b26040`. production/live/rewarded 설정, iOS 운영 광고 ID, 승인된 `textbook.20261112.1` 해시, 개인정보 manifest를 확인했다. ATT 설명 키·원격 학습 분석·진단 기기 해시가 없으며 운영 광고를 직접 노출하거나 클릭하지 않았다. [아티팩트 검사](evidence/ios-release-040-20261112/artifact.json).
- 스토어 설명·업데이트 내용·심사 메모를 60회 구성과 기존 권한 보존에 맞춰 변경했다. 기존 심사 연락처·개인정보 신고는 유지했다. [메타데이터](evidence/ios-release-040-20261112/metadata.json).
- 기존 20회 목록 스크린샷만 현재 60회·권 탭 화면으로 교체했다. iPhone은 기존 별도 테스트 앱을 6.5형 시뮬레이터에서 직접 캡처했고, iPad는 이미 확보한 이번 버전 시뮬레이터 캡처를 사용했다. 새 화면 캡처를 별도 실기기·동의 QA 통과로 계산하지 않는다. 두 이미지의 Apple 처리 COMPLETE를 확인했다. [이미지 처리](evidence/ios-release-040-20261112/screenshots.json).

## 업로드 및 제출

- 2026-11-12 08:43 KST 업로드 성공. Delivery UUID `5e6ace43-73a6-4606-b78c-6f2d6dd14dc0`, 종료코드0, `UPLOAD SUCCEEDED with no errors`. 업로더는 로컬 재시작 상태 파일 경고도 출력했으나 업로드 성공 후 Apple 서버에서 실제 VALID를 확인했다. [업로드 기록](evidence/ios-release-040-20261112/upload.json).
- Apple 처리 결과 `VALID`, 배포 대상 `APP_STORE_ELIGIBLE`. 기존 **SQLD Pass 내부 검증** 그룹에 빌드15를 추가해 `IN_BETA_TESTING`, 자동 알림 활성화를 확인했다. [TestFlight 기록](evidence/ios-release-040-20261112/testflight.json).
- 2026-11-12 **08:47 KST App Store 정식 심사 제출 완료**, `WAITING_FOR_REVIEW`, 승인 후 자동 출시 `AFTER_APPROVAL`. 제출 ID `065d2c2d-038a-48ba-87ac-83caa92e9a8e`. 제출 직전에 같은0.4.0(15) 빌드 연결을 확인했다. [정식 심사 기록](evidence/ios-release-040-20261112/app-store-submission.json).
- 제출 시점 공개 버전0.3.4(14)은 유지된다. 0.4.0의 심사 승인·공개 출시 완료를 주장하지 않는다. 새 운영 광고 빌드의 설정 확인과 이번 버전의 물리 광고 게재·동의 검증은 서로 다른 범위다.
- 내보내기 후 임시 서명 키체인을 제거하고 이전 키체인 검색 목록을 복원했다. 제출 완료 후 복원한 개인키·인증서·비밀번호·복구키·암호화 백업을 임시 경로에서 제거했다.
