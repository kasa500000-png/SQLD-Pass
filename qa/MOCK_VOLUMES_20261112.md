- 첨부 HTML2개를 gzip으로 보관하고 원문 해시를 검사했다.

- 기존0.3.4의 모든 교재·일반문항·1권 문항·회차·출처 객체가 유지되는지 검사했다.
- 추가2,000문항의 지문·블록·보기·정답·보기별/전체 해설·결과 표·검산·교재 연결·주제·출처를 원문과 대조했다. 권별 주제 오연결·회차 순서·중복·표 너비 오류의 거부를 확인했다.
- `node --test tests/mock-volumes-content.test.cjs`:3개 통과. `npm run typecheck:native`:통과.
- 아직 실기기·광고 SDK 동작 및 신규 콘텐츠의 사람 검수를 의미하지 않는다. 운영 팩은20회이며60회 활성화는 통합 단계다.

- 전체 `npm test`:448개 통과(core TypeScript 포함). 새8개 상태·권한 시나리오와 실제 SQLite 브리지의 호환 업데이트·실패 롤백 검사를 포함한다.

# PR3 — 권별 실전 탐색

- 3권 탭, 권별 20회 목록, 응시 상태와 이용 가능 조건의 통합 필터를 구현했다. 필터는 적용 전 취소할 수 있고 권 선택은 실행 세션에만 유지한다.
- 진행 중·일시정지 회차는 선택한 권과 관계없이 상단에 표시한다. 결과에서 회차 목록으로 돌아가면 해당 권을 선택한다. 다음 회차 추천은 추가하지 않았다.
- `npm test`: 454/454 통과. 새 6개 검사는 권 전환·필터 적용/취소·기록 저장 제외·전역 진행 중 회차·신규 회차 광고 요청·결과 복귀·스크롤 복원을 확인한다.
- `npm run typecheck:native` 통과. 이 단계의 광고 검사는 모의 SDK이며 실제 광고·기기 증거가 아니다. 실행 콘텐츠는 아직 기존 20회다.
