# 핵심 노트·고정 복귀 구현과 검증

앱0.7.0 후보에 핵심 노트83개,7분류,필수45개,SQL·값 예제70개,빠른 암기12줄을 추가했다.
홈·교재·문제·실전·기록의 고정 상단에서 연다. 분류를 연속해서 읽고, 내용 검색·저장·
이어 읽기를 사용한다. 풀이 중에는 추가 진입 버튼이 없고 노트에는 광고가 없다.
기존 핵심 카드·용어 사전,216절·연습340문항·모의고사60회3000문항은 유지했다.

해설의 결과 복귀 버튼은 스크롤 본문에서 고정 제목 영역으로 이동했다. 결과에서
들어오면 `〈 결과` 하나로 돌아가며, 저장 목록 등 다른 경로는 원래 뒤로가기를 보존한다.
문항 필터·이전/다음·문항 선택과 기존 채점 정책은 그대로다. 큰 시스템 글자에서는
제목과 도구가 두 줄로 배치된다. 기본 Android360dp에서는 한 줄을 유지하도록 조정했다.

## 콘텐츠와 코드

- 통합 버전 `textbook.20261113.2`, 노트 `memory-notes.20261113.1`.
- SHA-256 `5473eb0f7f166e8caf7b4eb7dc168e6e42592449a1bf7064fccebb9f38adc64f`.
- [최종 노트 검수본](MEMORY_NOTES_CONTENT_REVIEW_20261113.md),
  [문구 수정 전후·근거](../content-source/memory-notes-corrections.json).
- 원본은 gzip과 SHA로 보관했다. DOM 파서는 JavaScript를 실행하지 않는다.
- `src/memory/`는 노트 모델·검색·네이티브 화면을 담당한다.
- `src/core/controller.ts`와 상태 파서는 기존 순차 SQLite 저장으로 저장·읽기 위치를 처리한다.
- `ReadingScrollView`는 검색으로 지정한 노트 위치를 먼저 열고 이후 실제 읽기 위치를 저장한다.
- 공통 제목 영역은 `src/textbook/views.ts`, `NativeView.tsx`에 적용했다.

## 출시 상태와 남은 범위

구현 PR85·86·87은 병합했다. 통합 PR은 콘텐츠 활성화,이 기록과 스토어 업데이트 문안을 포함한다.
새 후보의 직접 내용 검수 확인을 요청했으며 아직 답변을 받지 않았다. 기존0.6.0 검수는
이 해시의 승인이 아니다. 실제 production 게이트가 이전 해시를 거부함을 확인했다.
iPad 실물은 연결 불가로 새 검증을 하지 못했다. 0.6.0 예외를 이번 버전에 재사용하지 않는다.

0.7.0 TestFlight 업로드·양쪽 정식 제출·스토어용 archive/export는 아직 수행하지 않았다.
[출시 후보 상태](../release/CANDIDATE_070_20261113.json)를 따른다.
물리 iOS,VoiceOver/TalkBack 전체 탐색,모든 노트·SQL의 각 기기 전수 조작은 미수행이다.
성능·학습 효과 향상 수치를 측정하거나 추정하지 않았다.
