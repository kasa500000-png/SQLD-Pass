# 새 3권 추가 0.6.0 구현·검증 기록

대상은 SQLD Pass다. 기존 1·2권 40회에 원본 Vol.4 61~80회를 앱의 **3권 41~60회**로 추가했다. 교재 216절, 일반 연습 340문항은 그대로이며 모의고사는 60회·3,000문항이다. 콘텐츠는 `textbook.20261113.1`, SHA-256 `61316063d2112c7b5cd25773a662a61b9037925e375073131c094d2522ca9fd5`다.

각 권 첫 5회, 표시 1~5·21~25·41~45회는 무료다. 나머지 45회는 기존 플랫폼별 보상형 광고의 완료 이벤트로 해제한다. 광고 연령·동의, 시험 중 광고 억제, 90분 실전/무제한 학습 정책은 바꾸지 않았다.

## 승인과 작업 구분

소유자는 정확한 후보에 대해 **“새 3권 내용 검수 완료”**를 확인했다. 구현·PR 병합·운영 광고·양쪽 정식 제출 실행 권한은 기존 위임을 따른다. 기기는 **“Android만 연결 가능합니다”**라고 답했다. iOS 0.5.0의 생략 예외를 0.6.0에 재사용하지 않는다.

- 콘텐츠 #77, 호환 이관·권한 #79, 실전 탐색 #80, 기록·복습 #81을 분리하여 병합했다.
- CI 호환성에 필요한 Expo 57.0.33 / constants 57.0.24 / sqlite 57.0.5 패치는 #78로 분리했다. 광고 SDK 16.4.0은 유지했다.
- 최종 통합 #82에서만 실제 런타임 팩을 새 60회로 전환했고 CI 통과 후 병합했다.
- Android 0.6.0(23) 운영용 서명 빌드와 정식 프로덕션 제출을 완료했다. 2026-11-13 13:19 KST 서버에서 검토 중인 6개 변경사항을 확인했다. 승인 후 100% 자동 출시이며 아직 공개 출시 완료는 아니다. [실행 기록](../release/STORE_STATUS_060_20261113.json)을 따른다.
- iOS 0.6.0(17)은 TestFlight 내부 그룹 업데이트와 App Store 정식 심사 제출을 완료했다. 서버 상태는 WAITING_FOR_REVIEW이며 승인 후 자동 출시다. 소유자의 새 지시 “이번에도 예외 진행”에 따라 이번 버전의 추가 iPad 실기기·iOS 동의 재검증은 미수행으로 기록했다. [iOS 실행 기록](IOS_RELEASE_060_20261113.md).

## 외부 상태와 남은 범위

AdMob의 SQLD Android/iOS 앱은 2026-11-13 `준비됨 / 광고 게재 사용 설정됨`이다. Android 배너 자동 새로고침은 사용중지 상태다. 공개 app-ads.txt의 직접 판매자 값과 개인정보·지원 URL 200 응답을 확인했다. 이번 변경은 광고 SDK·권한·수집 목적을 추가하지 않으며 학습 정보는 기기 내부에 남는다.

지원 사이트는 기존 버전 17을 유지한다. Sites가 `codex_auth` 자격 방식으로 응답하지만 설치된 공식 helper가 이를 지원하지 않아 checkout을 완료하지 못했다. 새 60회 설명을 사이트에 게시했다고 기록하지 않는다. 앱과 스토어 문안에는 새 구성을 반영한다. 기존 개인정보처리방침의 처리 범위는 그대로다.

물리 iPad, VoiceOver/TalkBack 전체 탐색, 모든 60회 실기기 완주, 모든 문항의 실제 DBMS 정답 검증은 미수행이다. 사용자 과업 성공률·성능 개선 수치는 측정하지 않았다. iOS 시뮬레이터 결과를 실물 iPad 증거로 대체하지 않는다.

## 운영 Android 파일 검증

실제 서명 AAB/APK 0.6.0(23)을 빌드했다. APK 인증서 SHA-256은 `ea1e8482b51d7a905271eecdabf840e244adcfaaed7da559329cb929e7171942`이며 bundletool 검증과 JAR 서명 확인을 통과했다. JAR 검사에서 자체 서명 업로드 인증서·타임스탬프 없음·ZIP manifest 순서 경고가 있었으나 서명은 검증되었고 Google Play가 업로드를 수락했다.

APK/AAB의 실제 JS 번들과 app.config가 동일하다. production/live/rewarded, 새 콘텐츠 승인 해시, 운영 AdMob 앱 ID, 비디버그 및 광고 식별자 권한 제외를 확인했다. 35개 네이티브 라이브러리의 16KB 검사 실패는 0이다. [파일 검증 결과](evidence/curated60-20261113/android-production-artifact.json)에 파일 해시와 상세 결과를 남겼다.

Google Play 검토 화면은 지원 기기 감소 0과 차단 오류 0을 표시했다. 난독화 매핑 파일 미첨부 경고 1개는 남아 있다. R8 최적화는 이번 콘텐츠 추가 범위에서 변경하지 않았다. 기존 공개 0.5.0 대시보드의 DEX 최적화 권고와 2027년 2월 기한은 후속 점검 대상으로 남긴다.
