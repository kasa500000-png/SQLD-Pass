# SQLD Pass 홈 UX 검토 — 2026-09-26

## 결론

큰 레이아웃 개편은 필요하지 않다. 핵심 버튼이 명확하고 본문/탭의 잘림 없이 홈 전체를 한 화면에서 볼 수 있다. 다만 읽던 위치를 복원하지 않는 이어하기는 실제 학습 흐름을 끊으므로 우선 보완할 가치가 있다. 오늘 분량/진도를 한 줄로 보여주고 최초 시작 버튼 이름을 구분하는 소규모 변경을 권장한다.

## 확인 범위

- 연결된 실제 휴대폰: Samsung SM-F721N, 1080×2640, density 480.
- 설치되어 있던 SQLD Pass는 9월 19일 내부검증 구버전이었다. 9월 20일 학습 UI 간소화 작업으로 생성한 `android/app/build/outputs/apk/release/app-release.apk`를 `adb install -r`로 업데이트했다. 데이터 삭제 없음.
- 이 APK는 Play 내부테스트 0.1.0 (2)에 포함된 동일 UI 소스의 검증용 패키지 `com.sqldpass.app.internal`이다. Play 패키지 직접 설치, 현재 프로덕션 게시 상태 또는 스토어 업데이트 검증으로 해석하지 않는다.
- 최초 시작 화면 상태여서 기본 학습 설정(45분, 목표 시험일 비움)으로 진입했다. 온보딩 완료 설정만 저장했고, 읽음/북마크/답안/시험/광고 기록은 생성하지 않았다.
- 홈 상단과 아래 방향 스와이프 후 전체 영역, 학습 진입/복귀, 30일 학습 계획 진입/복귀를 확인했다. 마지막 화면은 홈으로 돌려놓았다.
- 신규 사용자 상태를 실제 기기에서 검토했다. 누적 복습·진행 중 시험·광고 노출·태블릿·iOS 상태는 이번 실기기 검토에 포함하지 않았다.

## 발견 사항

| 우선순위 | 실제 관찰 / 근거 | 사용자 영향 | 권장 변경 |
|---|---|---|---|
| 1 | 홈 → 학습 이어하기 → 이론 중간까지 스크롤 → 뒤로 → 학습 이어하기 시 LESSON 01 맨 위로 복귀 | 잠깐 중단할 때마다 읽던 부분을 다시 찾아야 함 | 최근 이론과 읽던 위치 복원. 시험/확인 문제의 기존 복구 흐름과 구분하여 구현 |
| 2 | 홈에는 `0 / 30일`, `0%`, 진행 바와 다음 이론 제목만 표시됨. 계획 화면에는 Day 1 `3개 레슨 · 권장 25분`이 표시되고 콘텐츠에는 확인 문제 6개가 배정됨 | 오늘 얼마를 해야 하는지, 하루 분량 중 얼마나 했는지 알기 어려움 | 기존 카드에 `이론 0/3 · 확인 0/6` 및 다음 이론의 `약 9분`처럼 짧은 분량/진도 표시. 전체 30일 진도는 보조 정보로 유지 |
| 3 | 읽기/풀이 기록이 없는 최초 홈에서도 버튼명이 `학습 이어하기` | 시작과 재개의 의미가 불일치 | 최초 `학습 시작`, 진행 이후 `이어서 읽기`/`확인 문제 이어하기` 등 상태별 명칭 |

`0/30일`은 과정 전체 완료율로서 계산 자체가 잘못된 것은 아니다. 오늘의 진행도를 함께 보여주어 의미를 구분하는 개선이다.

## 유지할 부분

- 홈·학습·실전·기록 4개 탭과 한 개의 강조된 학습 버튼.
- 읽기 쉬운 글자, 넉넉한 터치 영역, 간단한 카드 구성.
- 하단 여백만을 이유로 새 통계/배너/설명 카드를 추가하지 않는다. 필요한 정보는 기존 학습 카드 안에서 정리한다.
- 콘텐츠 원문, 채점, 광고 해제 정책은 이번 검토와 변경 대상이 아니다.
